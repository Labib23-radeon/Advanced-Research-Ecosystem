# Advanced-Reasearch-Ecosystem
Local-first autonomous AI research agent. A ReAct loop with small Ollama models plans queries, searches DuckDuckGo, Wikipedia and arXiv, reads web pages and PDFs, stores chunks in ChromaDB, and writes citation-grounded Markdown reports. Includes a six-tier JSON recovery parser, a FastAPI web workspace and a CLI. No API keys, no per-query cost.
